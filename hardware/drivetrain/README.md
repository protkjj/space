# 구동계 메모

현재 baseline은 다음과 같습니다.

- 4륜 스키드스티어
- 엔코더 내장 브러시 DC 기어모터
- 좌/우 모터를 묶는 RoboClaw 계열 2채널 드라이버
- 목표 주행속도: 0.1 ~ 0.3 m/s
- 목표 로버 중량: 2.5 kg

## 모터 계산에 필요한 값

- 최대 경사각
- 단차/장애물 높이
- 바퀴 직경과 폭
- 모래 입자 지형의 구름저항 추정값

모터는 경사 등판, 단차 극복, 입자 지형 주행 중 가장 큰 부하를 기준으로 선정합니다. 스키드스티어는 제자리 회전 때 부하가 커질 수 있으므로 안전계수에 회전 부하를 포함해야 합니다.
